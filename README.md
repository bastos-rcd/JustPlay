# JustPlay

Multi game application

## Setup

1. Clone repository

   ```bash
   git clone https://github.com/bastos-rcd/JustPlay.git
   cd JustPlay
   ```

2. Install dependencies

   ```bash
   npm install
   ```

3. Start application

   ```bash
   npm run dev
   ```

4. Open application `http://localhost:3000`
